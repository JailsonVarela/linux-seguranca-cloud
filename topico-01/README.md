# Topico 1 - Administracao para Linux em Cloud

## Ambiente utilizado
Killercoda - Browser

## Objectivo desta atividade
Preparar o ambiente Linux e organizar a primeira evidencia tecnica.

## Estrutura criada
Criei uma pasta "linux-seguranca-cloud", dentro dela criei as outras pastas com nomes "produto-final" e "admin-linux-cloud" a partir da ultima pasta os ficheiros "README.md", "comandos-admin-linux-cloud" e a pasta "evidencia".

## Comandos executados
1. mkdir - criar pastas
2. cd - avancar para outra pasta
3. cd .. - retroceder uma pasta
4. touch - criar ficheiros

## Diferenca entre VM, VPS e infraestruturas em nuvem
* **VM** imagem do sistema operativo, local.
* **VPS** local
* **infraestrutura em nuvem** facil, pratico, com limitacoes.

## Dificuldades encontradas
O principal problema que enfrento e' de espaco para garantir a performance do sistema. Ja' tenho espaco reduzido porque tenho dual-boot e para experimentar algo novo quero seguir uma opcao leve e mais comum no mercado atual de trabalho.
